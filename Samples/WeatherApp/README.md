# WeatherApp

RayoUI port of the .NET MAUI WeatherTwentyOne sample. The shared project is
hosted by both `WeatherApp.Desktop` and `WeatherApp.Android`.

```powershell
dotnet run --project ..\WeatherApp.Desktop\WeatherApp.Desktop.csproj
dotnet build ..\WeatherApp.Android\WeatherApp.Android.csproj
```

The sample includes responsive desktop/phone navigation, current conditions,
hourly and seven-day forecasts, searchable favorites, an interactive wind-map
visualization, unit selection, and light/dark themes.
